# ASTRA Backend

Owned by Person 4.

This service receives validated outputs from the other ASTRA components, stores them, manages alerts and synchronization, and exposes APIs for the frontend.

Tech stack: Python, FastAPI, Pydantic v2, SQLAlchemy, SQLite, Alembic, pytest, and HTTPX.

Do not add authentication, frontend logic, emotion detection, state inference, or LLM logic here.
